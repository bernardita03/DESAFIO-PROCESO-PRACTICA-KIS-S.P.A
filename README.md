# DESAFIO-PROCESO-PRACTICA-KIS-S.P.A
Este proyecto es una aplicación web interactiva que permite explorar tablas de bases de datos, visualizar datos en una grilla y aplicar filtros dinámicos mediante un sistema de arrastrar y soltar. Está desarrollado con **HTML**, **CSS**, y **JavaScript** utilizando [Supabase](https://supabase.com) como backend.

## 🚀 Funcionalidades

- **Exploración de Tablas y Campos:** Selecciona tablas de la base de datos y explora sus campos de forma dinámica.
- **Sistema de Grilla Dinámica:** Visualiza los datos seleccionados en una tabla interactiva.
- **Filtros Personalizables:** Crea filtros dinámicos para buscar datos específicos.
- **Botón de Limpieza:**  Restablece fácilmente la grilla de datos y los filtros.
- **Interfaz moderna y amigable:**  Incluye un diseño atractivo y soporte para drag-and-drop.

## 🛠️ Tecnologías utilizadas

- **Frontend:**
  - HTML5
  - CSS3
  - JavaScript (ES6+)
- **Backend:**
  - Supabase (PostgreSQL como base de datos)
  
## 📋 Requisitos

Antes de comenzar, asegúrate de tener instalado:

- Navegador moderno (Chrome, Firefox, Edge, etc.)
- Acceso a una base de datos Supabase configurada.
